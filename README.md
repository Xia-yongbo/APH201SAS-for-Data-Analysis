## Coursework 1 临床试验数据整理与变量构建

### 项目背景

第一次作业基于 **CSP-1018** 研究。该研究关注丁丙诺啡/纳洛酮舌下含片作为门诊治疗阿片类药物依赖方案的安全性。作业使用两张来源不同但可以通过患者编号关联的数据表：

- `scr`：筛查表，包含患者基本信息、入组状态和日期等变量；
- `phys`：体格检查表，包含身高、体重、血压、脉搏及多个身体系统的检查结果。

这次作业的重点不是直接建立统计模型，而是先把分散的临床记录整理成结构清晰、变量含义明确、能够支持后续分析的数据集。

### 我完成的工作

1. **建立 SAS 数据环境**  
   我建立了课程专用数据目录和 SAS library，使原始数据和生成的数据集可以被统一管理。

2. **筛选研究对象并规范变量**  
   我从筛查数据中提取中心编号、患者编号、性别、年龄、种族、入组状态及相关日期，只保留实际入组的受试者，并把原始问卷变量名重命名为更直观的分析变量。

3. **合并临床数据表**  
   我按患者编号对筛查数据和体格检查数据进行排序和匹配合并，生成 `task1` 数据集。提交的 SAS 输出显示，该数据集包含 **797 条观测和 45 个变量**。

4. **完成单位转换和衍生变量构建**  
   我把英寸和磅分别换算为米和千克，据此计算 BMI，并按照体重不足、正常、超重和肥胖四个区间创建 BMI 分类变量。同时，我为性别、种族和 BMI 分类设置了便于阅读的显示格式。

5. **处理日期和体格检查信息**  
   我将数值日期转换为实际日期，计算入组日期与首次用药日期之间的时间间隔，并统计 11 项体格检查指标中被记录为异常的项目数量，形成更适合后续分析的汇总变量。

6. **检查并展示结果**  
   我使用 `PROC CONTENTS` 核对数据结构，并输出关键数据集的前若干条记录，以检查变量、格式和计算结果。

### 这次作业体现的能力

CW1 让我认识到，健康数据分析的可靠性首先建立在数据管理之上。它训练了我阅读数据字典、理解临床表单、确定合并键、进行单位与日期转换、构建派生变量，并通过程序输出验证处理结果的能力。这些步骤也是临床研究和生物统计分析中把原始数据转化为分析数据集的基础。

## Coursework 2 心血管数据统计分析与建模

### 项目背景

第二次作业使用 `frmgham2.csv` 中的 Framingham 心血管健康数据。与 CW1 侧重数据准备不同，CW2 要求我围绕总胆固醇、BMI、血压、糖尿病、吸烟、教育程度和心血管疾病等变量，完成从描述性分析到统计建模的完整流程。

### 我完成的工作

1. **数据分组、列表和可视化**  
   我按年龄建立三个分组，制作性别与年龄组的频数表；筛选年龄大于 75 岁且患有糖尿病的人群，分别生成男性和女性的血压列表；并绘制不同年龄组总胆固醇水平的箱线图。

2. **描述统计和相关分析**  
   我分别按性别计算 BMI、血糖、收缩压和舒张压的中位数、四分位数、最小值和最大值，并分析这些指标与心血管疾病状态之间的相关关系及其显著性。

3. **假设检验**  
   我使用单样本 t 检验比较样本总胆固醇均值与 200 mg/dL 的标准值。报告中的样本均值为 **241.2 mg/dL**，95% 置信区间为 **240.3 至 242.0 mg/dL**，检验结果为 **p < 0.0001**。  
   我还检查了 BMI 的分布，并使用两独立样本 t 检验和 Wilcoxon-Mann-Whitney 检验比较两个性别组的 BMI。两种检验均显示组间差异具有统计学显著性（**p < 0.0001**），使我能够比较参数方法和非参数方法在同一问题中的应用。

4. **多元线性回归**  
   我以总胆固醇 `TOTCHOL` 为结局变量，将性别、年龄、BMI、教育程度、当前吸烟状态和每日吸烟量纳入模型，并为分类变量建立虚拟变量。在完整模型中，共使用 **10,827 条完整观测**；整体模型具有统计学显著性（**p < 0.0001**），报告的 R² 为 **0.0505**。我随后进行了逐步变量选择，并结合残差图检查模型假设。较低的 R² 也提醒我区分“统计学显著”与“模型能够解释多少变异”。

5. **Logistic 回归和模型比较**  
   我以是否发生心血管疾病 `CVD` 为结局，纳入人口学特征、BMI、吸烟、降压药使用、糖尿病和血压等因素，分别拟合完整模型和逐步选择模型。我比较了 AIC、SC、-2 Log Likelihood 等拟合指标，并使用一致性百分比、Somers' D 等指标评价预测区分能力。逐步模型保留了收缩压、性别、年龄、糖尿病、当前吸烟、BMI、降压药使用、舒张压和一个教育程度指标；报告中的预测一致性为 **73.8%**。此外，我整理了完整模型中各变量的优势比、95% 置信区间和显著性。

### 这次作业体现的能力

CW2 展示了我如何把一个公共卫生问题拆解为可执行的统计步骤：先了解变量分布和缺失情况，再进行组间比较，随后建立多变量模型并评价模型表现。相比只报告 p 值，我开始关注置信区间、效应量、拟合优度、变量选择和诊断图，并意识到统计显著性、解释能力与预测能力并不是同一概念。

## 两次作业之间的能力进阶

这两次作业共同构成了一条清晰的学习路径：

**原始临床记录 → 数据清洗与合并 → 衍生变量构建 → 描述统计与可视化 → 假设检验 → 多变量回归 → 模型比较与解释**

CW1 让我掌握了“如何把数据准备好”，CW2 则进一步训练了“如何用准备好的数据回答健康研究问题”。这条从数据质量到统计推断的路径，是我希望在生物统计、公共卫生或健康数据科学硕士阶段继续深化的方向。
